# Checklist — add-pcb-design-mod

> 每个 checkpoint 对应 spec.md 中的 Requirement / Scenario。验证通过后勾选。

## 工程脚手架
- [x] Forge 1.20.1 / Java 17 工程可 `gradlew build` 通过并生成可运行 jar
- [x] 模组能在客户端启动，日志显示 `pcbcraft` 加载成功，无原版行为变更
- [x] `pcbcraft-client.toml` / `pcbcraft-common.toml` 配置项可读取并生效（DRC 默认值、仿真预算、沙盒限额）

## PCB 编辑器 GUI
- [x] 编辑器展示可配置图层列表（铜/阻焊/丝印/钻孔），可切换可见/可编辑，默认铜层 2 层
- [x] 元件库选择后点击放置焊盘，支持旋转/移动/删除，非法重叠被阻止
- [x] 布线工具生成当前铜层曼哈顿走线，宽度按网络，冲突高亮报错
- [x] 过孔在所有铜层建立连接并在阻焊层开窗
- [x] DRC 检查最小线宽/间距/孔径/未连接/短路，错误列表定位坐标，致命错误禁止生成

## 元件库系统
- [x] `data/pcbcraft/components/*.json` 按 schema 加载（id/name/category/symbol/footprint/pins/model 字段齐全）
- [x] 内置基础元件齐全（R/C/L/二极管/LED/按键/电源/地/六类逻辑门/D 触发器/运放/微控制器/连接器）
- [x] datapack 扩展元件可被加载，错误格式记日志并跳过而不崩溃

## PCB 方块实体生成与渲染
- [x] 通过 DRC 的设计可生成多层堆叠方块（层数 = 铜层 + 阻焊 + 丝印）
- [x] BlockEntity NBT 持久化完整设计数据，区块重载后恢复
- [x] 铜层铜色/阻焊绿色露焊盘/丝印白色位号，潜行+右键切层可见性

## 实时电气仿真引擎
- [x] 上电后用简化 MNA 求解节点电压与支路电流
- [x] 单板每 tick 计算预算 ≤ 1ms（可配置），超限降帧/分片不卡服
- [x] 信号沿走线按长度延迟传播
- [x] 不同网络短接触发保护（断开/限流）并冒烟告警
- [x] 元件过载累积发热，达阈值烧毁变黑失效，热扩散影响相邻元件
- [x] 无电源/开路网络电压为 0 并提示开路，杜绝红石式无限供电

## 可编程芯片方块与受限脚本
- [x] 右键芯片方块打开编程终端，API（pin.read/write/sleep/print/analog.read/pwm）可用
- [x] Luaj 沙盒去除 io/os/loadfile，每 tick 指令数/内存超限安全中止并报错到终端
- [x] `pin.write` 驱动网络表电平，`pin.read` 反映仿真电平，双向联动

## 调试与玩家交互工具
- [x] 探针右键走线/焊盘显示电压/电流/网络浮窗，可选波形采样
- [x] 信号流动可视化：高红/低蓝染色、电流粒子方向、模拟信号渐变色
- [x] 焊台物品可拆焊/换件并增量更新网络表，无需重新编译
- [x] 电压全局视图按节点电压热力色（蓝→红）染色整板

## 集成与本地化
- [x] 合成配方提供所有新物品/方块的获取路径
- [x] en_us 与 zh_cn 语言文件覆盖物品/方块/UI/提示
- [x] 端到端：LED+电阻+电源点亮回路成立
- [x] 端到端：逻辑门组合实现半加器
- [x] 端到端：芯片固件 blink LED
- [x] 端到端：短路保护与过载烧毁演示生效
